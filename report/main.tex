\section{Complexity}

The time complexity for the Naive-Gauss elimination in terms of the number of equations (\texttt{n}) is $\mathcal{O}(n^3)$. This is because there are three nested loops, meaning there are three operations successively using \texttt{n}, resulting in the complexity being $\mathcal{O}(n^3)$.

\section{Pseudo-code}

\begin{algorithm}
\caption{Naive Gaussian Elimination}
\begin{algorithmic}[1]
\For{$j= 0$ to $n$}
    \For{$i = 0$ to $n$}
        \If{i != j}
            \State $factor = \frac{A_{ij}}{A_{jj}}$
            \For{$k = 0$ to $n+1$}
                \State $A_{ik} = A_{ik} - factor \cdot A_{jk}$
            \EndFor
        \EndIf
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}
